# 霓虹弹珠台 · NEON PINBALL

纯前端、零依赖的 2D 弹珠台游戏。三张台面可选，代码按模块拆分，不引用任何外部库、CDN、图片或音频资源。

## 在线试玩

部署到 GitHub Pages 后，链接形如：

```
https://<你的用户名>.github.io/<仓库名>/
```

## 本地运行

双击 `index.html` 即可（页面用普通 `<script>` 加载，`file://` 下也能跑）。也可以用任意静态服务器：

```bash
python -m http.server 8080
```

## 目录结构

```
index.html            页面骨架：状态栏 / canvas / 遮罩 / 触控按钮
css/main.css          页面样式、台面选择卡片、移动端适配
js/config.js          全局可调参数（重力 / 反弹 / 挡板 / 发射 / 轨道 / 镜头）
js/utils.js           数学与几何工具：clamp、限速、墙壁法线、胶囊挡条、圆角矩形
js/audio.js           WebAudio 实时合成音效
js/tables.js          三张台面的数据定义 + 运行时构建（法线、轨道采样、元件副本）
js/flipper.js         挡板（胶囊碰撞 + 旋转线速度）
js/effects.js         粒子 / 飘字 / 冲击波 / 镜头推近 / 慢动作 / 命中停顿
js/materials.js       程序化材质：台面底板烘焙、拉丝 / 碳纤 / 星云纹理、噪点
js/physics.js         碰撞求解与固定步长物理主循环、弧形轨道、多球
js/renderer.js        渲染层：金属墙体、玻璃缓冲器、镀铬弹珠、拉丝挡板
js/game.js            游戏状态机、计分、台面切换、最高分
js/main.js            启动、DOM 绑定、输入、尺寸自适应、主循环
```

模块通过 `window.PB` 命名空间串联（每个文件一个 IIFE），加载顺序即依赖顺序。

## 三张台面

| 台面 | 特色 | 内容 |
| --- | --- | --- |
| **霓虹经典** `classic` | 对称四缓冲 + 环形轨道 | 4 缓冲器、12 钉子、2 目标灯，轨道半径 190 |
| **熔金回廊** `gallery` | 两条金属导流墙把球推向中央，轨道更长 | 3 缓冲器、8 钉子、3 目标灯，重力略低、轨道计分 50 |
| **深渊之核** `abyss` | 五瓣缓冲核心 + 密集钉阵 | 5 缓冲器、11 钉子、3 目标灯，重力更重、钉子弹力更强 |

- 开局界面用卡片选择台面，`←` `→` 也能切换；选中的台面会被记住
- 每张台面独立记录最高分（`localStorage` 中按台面 id 分键）
- 三张台面共用外壳与物理参数骨架，各自在 `def.cfg` 里覆盖细节（重力、缓冲冲量、轨道奖励、挡板长度等）

## 玩法与计分

- 共 3 颗备球；场上所有球都掉进底部掉球区才扣 1 颗，备球用完游戏结束
- 圆形缓冲器 **+100**（命中会明显弹开并脉冲放大）
- 小钉子 **+10**
- **目标灯全部点亮 +500**，随后自动重置（三张台面分别有 2 / 3 / 3 盏）
- **弧形轨道（顶部）**：把球顺着轨道方向打进橙色入口，球会脱离物理、沿路径点滑行越过顶部弧线，从另一端甩出
  - 途中每经过一个计分点 +40（熔金回廊为 +50，共 8 点）
  - 完整走完再 +200（深渊之核 +260），并**触发多球模式**（额外放出 2 颗球，场上最多 3 颗）
- 多球模式下掉球不扣命，只有场上球全部掉光才扣 1 颗备球
- 连续命中会显示 COMBO 提示

## 材质与视觉

- **台面底板**一次性烘焙到离屏 canvas（`materials.js`），每帧只做一次 `drawImage`：
  - 拉丝金属：数百条随机横向细线 + 冷调高光带
  - 碳纤编织：±45° 网格 + 交替暗格 + 暖色环境光
  - 星云：低透明色团 + 星点
  - 统一叠加深色暗角与 128×128 噪点瓦片，磨砂颗粒零运行时开销
- **弹珠**：镀铬径向渐变 + 接触阴影 + 边缘反射弧 + 镜面高光 + 极细亮边，高速时额外动态高光
- **缓冲器**：玻璃罩（多段径向渐变）+ 右下暗面做出球体体积 + 金属压环 + 内环 + 玻璃高光弧，命中时脉冲放大
- **挡板**：沿法线方向的明暗渐变模拟圆柱拉丝金属，顶缘高光条 + 霓虹底光 + 金属轴心盖
- **墙体**：深色板材 + 霓虹外发光 + 高光芯三层叠加；台面内部的导流墙用实心胶囊，两面都实心
- **钉子 / 目标灯**：镀铬半球 + 接触阴影；目标灯带呼吸虚线圈与玻璃反光
- 全局再叠一层极淡的玻璃反光，统一表面观感

## 技术实现

- 逻辑分辨率 480×800，Canvas 按容器等比缩放并适配 devicePixelRatio
- `requestAnimationFrame` 主循环 + 固定物理步长 1/120s，每步 3 个子步防止穿透
- 碰撞：圆-线段（半平面 / 胶囊）、圆-圆、圆-顶部圆弧、圆-挡板胶囊、圆-三角撞块
- 挡板旋转时把接触点线速度（`ω × r`）合入反弹计算，形成真实弹射
- 弧形轨道用「路径点 + 参数化位置」实现：由参数方程采样 65 个点，球进入后位置由 `t ∈ [0,1]` 沿路径点线性插值，切向决定出射速度
- 球是数组（`state.balls`），多球模式共用同一套物理与绘制，`b.rail` 非空表示该球在轨道上
- 音效由 WebAudio 实时合成，首次用户交互后初始化
- 所有可调参数集中在 `js/config.js`，台面级覆盖写在 `js/tables.js` 的 `cfg` 字段

## 镜头与打击感

时间被刻意拆成三条互不干扰的线，避免「减速把操作也拖慢」这类典型问题：

| 时间线 | 驱动的对象 | 是否受 hitstop / 慢动作影响 |
| --- | --- | --- |
| `dt` | 挡板旋转、输入、各类冷却计时 | 否，永远按真实时间走 |
| `simDt` | 物理积分、粒子、闪光、冲击波 | 是 |
| 相机 | 缩放回落、震屏衰减 | 否，只用真实时间 |

- **命中停顿（hitstop）**只冻结物理，挡板必须继续推进——否则 `omega` 归零会让下一次碰撞读不到旋转线速度，弹射力凭空消失
- **慢动作**只用在有奖励含义的节点：入轨 0.6×、出轨道 0.45×、多球 0.35×
- **镜头推近（zoom punch）**焦点固定在 `(240, 200)`，只放大不缩小，上限 1.04
- **冲击波环**用于计分事件，**线状火花**用于物理碰撞
- 暂停时画面静止，会主动停掉绘制（`#overlay` 带 `backdrop-filter`，持续重绘会让浏览器每帧重新模糊整张画布）

## 部署到 GitHub Pages

```bash
# 1. 在 GitHub 新建一个空仓库（不要勾选 README），然后：
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

2. 进入仓库 → **Settings** → **Pages** → Source 选择 **Deploy from a branch** → Branch 选 `main` / `(root)` → Save
3. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> 若想要 `https://<用户名>.github.io/` 这样的根域名地址，把仓库命名为 `<用户名>.github.io` 即可。
